我的做法，与普通人的做法

Markdown + Claude Code 更适合进阶使用者；Word 或 Google Docs 对普通人更熟悉，也更容易开始。

我的实际流程

A. Markdown + Claude Code

适合愿意使用文件和 Claude Code 的进阶使用者。

  • AI Agent 持续整理 Project 内容
  • 用 .md 文件保存结构、资料和决定
  • Claude Code 读取整个 Project 制作 PPT
  • 方便修改、重复使用和版本管理
OR
普通人最容易

B. Word / Google Docs

适合不使用程式工具，只想用熟悉文件开始的人。

  • AI Agent 先整理成有标题层级的文件
  • 每个段落只保留一个重点
  • 再交给 Canva AI 或喜欢的 PPT 工具
  • 最后自己选择模板和调整设计
