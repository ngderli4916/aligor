The Method

完整流程，其实只有 5 步

AI Agent 不是在最后一刻才出现。它从讨论、记录、确认到输出，一直都在同一个 Project 里面。

1

建立 Project

先告诉 AI Agent：这个 Project 的目标、对象、用途和最后要完成什么。

SET THE GOAL
2

持续讨论

把你的想法、案例、数据、照片、做法和所有细节，持续跟 AI Agent 讨论。

DISCUSS
3

边做边记录

让 AI Agent 把确认过的内容整理回 Project，而不是散落在不同聊天里面。

RECORD
4

完成后检查

确认资料、逻辑和重点都完整，再决定 PPT 的听众、场景与视觉风格。

VERIFY
5

一句话输出

让 AI Agent 直接制作 PPT，或先整理成专业结构，再放去你喜欢的 PPT 工具。

如果资料从来没有整理过，再厉害的 AI 也只能猜。真正高效的方法，是让 AI Agent 从第一天就参与。

Project Memory

Project 里面要记录什么？

不是把所有资料乱丢进去，而是把每次讨论后已经确认的内容，整理成 AI 随时可以使用的项目记忆。

5 类核心内容

一个可直接变成 PPT 的 Project，至少要有这些资料。

目标与对象讲给谁听、想达到什么结果
重点内容观点、步骤、案例、故事
事实与数据价格、数字、日期、证明
视觉素材照片、Logo、截图、参考风格
最终决定已经确认与不要再使用的内容

所有资料，围绕同一个 Project

Choose Your Style

最后有两种做法

没有规定一定要用哪一种。看你喜欢哪个工具、哪个设计风格，以及你要不要自己继续调整。

最直接

A. AI Agent 直接制作 PPT

适合想从内容到设计一次完成的人。

  • 直接读取 Project 已确认内容
  • 自动安排页数、结构与视觉节奏
  • 加入流程图、对比图、重点数字
  • 输出后再由你检查和修改
OR
风格自由

B. 先整理，再放去做 PPT

适合已经有自己喜欢的 PPT 工具或模板的人。

  • AI Agent 先整理标题与每页重点
  • 生成图表建议和视觉说明
  • 再放进你喜欢的 PPT 工具
  • 保留你原本的品牌与设计风格
One-Sentence Prompt

Project 完成后，就说这一句话

把方括号内的内容换成你的实际用途。因为所有资料之前已经整理好，所以这句话不是叫 AI 猜，而是叫它把完整 Project 转成清楚的视觉表达。

可直接复制

请根据这个 Project 里已经确认的全部内容，为［目标听众］制作一份专业、视觉化、可以直接讲解的 PPT；减少大段文字，多使用流程图、对比图、时间线、重点数字和清楚的图像层级，每一页只表达一个重点，并保持［你喜欢的风格］。

目标听众顾客、老板、员工、学生
使用场景课程、提案、报告、销售
喜欢的风格专业、简洁、活泼、高级
Final Check

生成后，不要马上交出去

AI Agent 帮你节省制作时间，但最后的事实、判断和对外内容，仍然要由你确认。

✓

检查事实

数字、价格、日期、名字和案例有没有错误。

◎

检查逻辑

每一页是否只讲一个重点，前后是否讲得通。

◫

检查视觉

文字会不会太多，图表是否真的帮助理解。

→

检查行动

观众看完以后，是否知道下一步要做什么。

不要从空白 PPT 开始。
从一个完整的 Project 开始。
