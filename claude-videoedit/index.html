01需要准备的工具

Claude Code负责“剪辑”的 AI Agent。我用的是 Claude 桌面版里的 Code。它会读你的视频、写剪辑方案、做动画、导出成品。
HyperFrames（Skill）给 AI 用的视频制作工具。字幕、动画、Logo、封面，都是它做出来的。
video-use（Skill）帮 AI 处理“剪片”的工具：转写语音、剪掉卡顿和停顿。
ElevenLabs API Key用来把你讲的话转成文字（逐字时间轴）。字幕准、卡顿也剪得准，中英夹杂也听得懂。
一台电脑（我用 Mac）视频在你自己的电脑上做，素材不用上传到别人的平台。

02第一次设置（只做一次）

  1. 安装 Claude Code（Claude 桌面版或终端版都可以），登录你的账号。
  2. 在 Claude Code 里直接跟它说：帮我安装 HyperFrames 和 video-use 这两个 skill。它会自己处理安装。
  3. 去 elevenlabs.io → API Keys 建一个 key（sk_ 开头）。
  4. 把 key 设成电脑的环境变量，名字一定要是 ELEVENLABS_API_KEY：
# Mac 用 zsh 的话写进 ~/.zshrc；用 bash 的话写进 ~/.bash_profile
export ELEVENLABS_API_KEY="sk_你的key"
注意：变量名字少一个下划线，AI 就读不到 key（我自己就踩过这个坑）。key 不要贴到群组或公开的地方。

03录视频的小技巧

  • 竖屏 9:16 录，脸放在画面中间偏上，头顶留一点空间给动画。
  • 光线对着脸，收音尽量靠近嘴巴。剪辑救不回拍得不好的画面。
  • 讲错没关系，停一下重讲。卡顿、重复，AI 会帮你剪掉。
  • 有“证据”就一起录：后台数据截图、手机录屏、聊天记录，比什么动画都有说服力。
iPhone 用户必看：iPhone 默认用 HDR 录影。剪出来如果颜色变淡、灰灰的，就是 HDR 没转好。跟 AI 说一句：这是 iPhone HDR 视频，先用 avconvert 转成 SDR 再剪，颜色要跟原片一样。

04丢给 AI：我的 Prompt

把视频（和录屏、截图）的路径丢给 Claude Code，然后贴下面这段。[ ] 里的内容换成你的。

PROMPT ① 剪辑 + 动画 
帮我用 HyperFrames 剪辑这个视频，我要发在 Instagram。

视频：[视频文件路径]
其他素材：[录屏 / 截图路径，没有就删掉这行]

要求：
1. 开头一定要有 Hook，前 3 秒让人不想划走。可以用视频里最有冲击力的一句话或数据放在最前面。
2. 我讲话卡顿、停顿、重复的地方全部剪掉，内容要顺。剪接点用推近镜头盖过去。
3. 转写用 ElevenLabs（ELEVENLABS_API_KEY），字幕要准确，关键词标色。
4. 讲到品牌、工具的时候，放出正确的官方 logo。
5. 讲到流程、数据、对比的地方都要做动画，整条视频动画不要停。
6. 所有动画和字都不能挡到我的脸，动画放在头顶的空白处。
7. 颜色要跟原片一样，不要加滤镜或暗角。iPhone HDR 视频先转成 SDR。
8. 结尾做清楚的引导：[例如：留言 edit / 去主页报名]。
9. 渲染前先截图给我看，检查没问题再导出 1080×1920 的成片。
PROMPT ② 封面 
用 HyperFrames 帮这条视频做一张 1080×1920 的封面（单独的图片，不要放进视频）。
把我从视频里最有表情的一帧抠出来，标题写：[你的标题]
要很吸引人点进来，重要的字放在中间 3:4 的范围里，不要挡到我的脸。
每次的设计风格都要不一样。
PROMPT ③ 文案 
帮我写这条视频的 Instagram 文案，要会让人看完、会想留言的那种。
第一行就是 Hook，数字只用真实数据，最后引导大家：[留言 edit / 去主页报名]。
最后加 5 个 hashtag。

05检查、修改、导出

  1. AI 会先给你几张截图，看看动画有没有挡到脸、字幕有没有错字。
  2. 想改就直接讲秒数和要怎么改，例如：36 秒那里换成我的 Instagram 主页截图，加点击报名的动画。
  3. 不在电脑前面也可以：叫它压缩一个 720p 给我手机看。
  4. 满意了，用 1080×1920 的原画质版上传，不要用压缩版。

颜色不对的话（变淡、发灰或偏色），把这段贴给 AI：

PROMPT ④ 颜色调对 
这条视频剪出来颜色不对（变淡、发灰或偏色），帮我调回跟原片一样。

原片：[原始视频文件路径]
成片：[剪好的视频文件路径]

要求：
1. 先检查原片是不是 iPhone HDR，是的话先用 avconvert 转成 SDR，再重新剪。
2. 成片的颜色、亮度、饱和度都要跟原片一样，不要加滤镜或暗角。
3. 从原片和成片各截同一秒的画面，左右并排给我看，确认颜色一样了再导出 1080×1920。

06封面和文案

  • 封面标题用“结果”说话：例如“冲到 6 万播放 · 我一刀都没剪”。
  • 文案第一行就是 Hook，中间放真实数据，结尾只给一个清楚的动作（留言或报名）。
  • 叫人留言关键字的话，记得设好自动回复或亲自私讯，不然留言的人会失望。

07常见问题

Q：我不会写代码，可以用吗？

可以。我也没有自己写代码，全部是用讲的，代码都是 AI 写的。

Q：剪出来颜色变淡？

九成是 iPhone HDR 的问题，看第 03 步的提醒。

Q：字幕错字很多？

确认 ELEVENLABS_API_KEY 有设好。没有 key 时，AI 会改用本地的 Whisper，免费但错字比较多。

Q：要另外装 Remotion 吗？

做 Instagram 短视频不用。HyperFrames 已经可以做数字跳动、图表、动画。
