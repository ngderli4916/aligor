Telegram Bot 是什么？

Bot 不是你自己的账号，是一个机器账号

你自己的账号

  • 你本人登入的 Telegram
  • 你用它发消息给 Bot
  • 不是拿来连接 Hermes 的

Bot（机器账号）

  • 不是你的账号，是一个机器账号
  • 用它来连接 Hermes Agent 最好
  • 它的 Token 是钥匙，自己保管
你的账号 ↔ Bot ↔ Hermes Agent：你对 Bot 说话，Hermes 在电脑做事
