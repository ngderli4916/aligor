STEP1
01 · 连接

先把 AI 装好，再把 WhatsApp 接上去。

顺序很重要：先确认 Hermes Agent 和大模型能正常回复，才去连接 WhatsApp。

a

安装 Hermes Agent，连接大模型大脑

两个方法选一个就好。新手建议从 Desktop 开始。

方法 ADesktop（新手较容易）

到 Hermes 官方网站下载 Desktop 版本，跟着画面安装。

打开 Hermes 官网 ↗

方法 BCLI（macOS / Linux / WSL2）

在 Terminal 运行官方安装命令：

安装curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

装好后运行设置向导，选择你要用的模型 Provider——这一步就是「连接大模型大脑」：

设置hermes setup
官方工具
b

先测试 Agent 本身能不能回复

还没碰 WhatsApp 之前，先打开 Hermes，问它一个简单问题，例如「你好，介绍一下你自己」。

它能正常回答，才进入下一步。否则之后没反应，你分不出问题出在大模型还是 WhatsApp。

c

连接 WhatsApp

① 在 Terminal 运行 WhatsApp 设置向导，按提示选择 bot 或 self-chat 模式：

连接 WhatsApphermes whatsapp

② 拿起手机，打开 WhatsApp，扫描 Terminal 显示的 QR：

WhatsApp→Settings→Linked Devices→Link a Device→扫 QR

③ 启动 Gateway，让它开始接收和回复信息：

启动hermes gateway
d

两种接法，差在哪里？

上面用的是 WhatsApp Web Bridge（扫 QR）。正式做生意，可以考虑官方的 Cloud API。

WhatsApp Web BridgeMeta WhatsApp Cloud API
怎样连接扫 QR，很快就接好Meta 官方路径
适合学习、测试、小规模使用正式商业使用
需要准备一个专用号码Meta Business、专用号码、公开的 HTTPS webhook
要注意属于非官方 Web 自动化，有账号被限制的风险；请用专用号码，绝对不要群发有 24 小时规则：超过 24 小时主动发信息，要用已批准的模板
!

小提醒：客服请用一个专用号码，不要用你的私人号码。测试阶段，只允许你自己和团队的号码，不要一开始就开放给所有顾客。

STEP2
02 · 训练（最关键）

接好只是开始，训练才决定它像不像你的员工。

给它三样东西：做事的规则、说话的语气、公司的资料。下面每一样都有模板，复制后改成你自己的内容。

训练 ①

公司 SOP

告诉它「怎样做事」：什么可以答、什么不能答、什么要交给真人。

SOP 模板
你是 [你的公司] 的 WhatsApp 客服。请遵守：
1. 顾客用什么语言，你就用什么语言回复。
2. 先回答顾客的问题，再问必要的资料。
3. 只使用「公司资料」里已批准的价格和政策。
4. 不确定的事情不要猜，也不要承诺。
5. 投诉、退款、付款问题，一律转给真人处理。
6. 顾客有购买意向时，记录：产品、数量、联络方式。
训练 ②

回复顾客的语气

告诉它「怎样说话」。同一个答案，语气不同，顾客感觉完全不一样。

✕ 不好：像机器人您好，感谢您的询问。该产品目前库存充足。请问您是否需要进行下单操作？
✓ 好：像真人店员有的哦 😊 今天下单明天就寄～要帮你开单吗？
语气模板
回复语气：
- 简短，一次只讲重点（2–3 句以内）。
- 亲切，像店里熟悉产品的店员。
- 可以用一两个 emoji，不要太多。
- 不用官腔，不说「您好，感谢您的询问」这类句子。
- 顾客急的时候，先安抚，再给答案。
训练 ③

公司资料

告诉它「答案是什么」。它只能根据你给的资料回答，所以要写清楚。

资料模板
公司名称：[你的公司]
营业时间：[例：星期一至六 10am–7pm]
地址：[你的店面地址]

产品：
- 名称：[产品名称]
  适合对象：[适合谁]
  价格：[RM 价格]
  库存：[有货 / 预购 / 缺货]

配送：[几点前下单当天寄出、运费、几天到]
付款：[接受的付款方式]
保修 / 退换：[条件和期限]

常见问题 + 已批准答案：
- 问：[顾客常问的问题]
  答：[你批准的答案]

更新时间：[YYYY-MM-DD]
负责人：[谁负责更新这份资料]

资料越清楚，它回复越像你的员工。

03 · 越用越精准

它不是装好就完美，是越用越准。

刚开始的几个星期，每天花一点时间看它的回复。你每修正一次，它下次就答得更好。

每天看回复

刚上线时，每天看一遍它回了什么。

找出答错的

哪一句不对、哪一句语气怪，记下来。

改资料 / SOP

修正公司资料或 SOP，删掉过期的价格。

加进 FAQ

顾客真实问到的新问题，加进常见问题和答案。

↺然后回到第 1 步。稳定以后，改成每星期检查一次。
04 · 安全边界

它什么时候不该自己回？

好的 AI 客服不是每一句都抢着答，而是知道自己的界限。

答

可以自动回复

营业时间、地址、产品资料、已批准的 FAQ、下单步骤。

问

先问一个必要问题

答案要看情况时，例如预算、型号、订单号码，先问清楚再答。

转

必须转人工

投诉、退款、付款异常、特殊折扣、顾客说要找真人。

停

看不懂就不要猜

只发「1」、看不清的截图、意思不清楚的信息——不乱猜，交给人。
