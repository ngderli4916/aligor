Landing Page 是什么？一页只做一件事

就像一个超级业务员：站在门口，只说一句最重要的话

🏬普通网站

  • 很多页面、很多菜单
  • 什么都讲一点
  • 顾客逛一圈就走了

🎯Landing Page

  • 只有一页
  • 只有一个目标：让顾客「行动」
  • 例：WhatsApp 你、填表格、订购
一页，一个目标，一个按钮——越简单越有效

Header 是头，Footer 是脚

每一页网页，最上面和最下面都有

🔝Header（头）

  • Logo：你是谁
  • 菜单：去哪里（Landing Page 很少）
  • 主按钮：随时可以点

🔚Footer（脚）

  • 联络方式、地址、营业时间
  • 社交媒体链接
  • 版权、隐私政策
头：让人一眼认得你；脚：让人最后找得到你

阶段 8 · Landing Page + GitHub + Cloudflare

HTML：网页的骨架

  • 用「标签」告诉电脑：这是什么
  • <h1> 是大标题，<p> 是文字
  • <img> 是图片，<a> 是链接
  • 不用背，认得出来就好
index.html
<h1>你的店名</h1>
<p>一句话讲清楚你卖什么。</p>

<img src="images/cake.jpg"
     alt="草莓蛋糕">

<a href="https://wa.me/你的号码">
  WhatsApp 订购
</a>
看起来像在写信，对吧？这就是网页的骨架 🦴

  • 决定颜色、字体、大小、间距
  • 同一个骨架，换一件衣服就变样

JavaScript：网页的动作

  • 让网页会「动」、会「回应」
  • 点按钮弹出提示
  • 检查表格有没有填
  • Landing Page 只需要一点点
script.js
// 点按钮，弹出提示
button.onclick = () => {
  alert("收到！我们会尽快联络你");
};

// 表格没填名字就提醒
if (!name.value) {
  alert("请填写名字");
}
Landing Page 通常只用一点点——你不用学会它 🏃

阶段 8 · Landing Page + GitHub + Cloudflare

文案怎么写？标题和按钮

写给顾客看，不是写给自己看

😐普通写法

  • 标题：欢迎光临我们的公司
  • 按钮：提交
  • 「我们是最好的」

😃更好的写法

  • 标题：一句话讲清楚你卖什么、给谁
  • 按钮：动词开头，例：WhatsApp 订购
  • 讲顾客得到什么，不是你多厉害
不要编折扣、评价、库存——真实最重要

阶段 8 · 第一步：让 AI 采访你，写 brief

先把想法说清楚：Brief 比「帮我做漂亮网页」更重要

你要做

  1. 贴上 Prompt 07A
  2. AI 一次问你一个简单问题
  3. 照实回答，没有的说「还没有」
  4. 确认它整理的 brief

成功的样子

  • 有一份 landing-page-brief.md
  • 唯一目标、3 个卖点、联络方式都写清楚
  • 缺的写「待确认」，没有编造
Prompt 07A　让 AI 采访我，整理 Landing Page brief
我要做一个 Landing Page。请先看当前项目里的公司、产品和联络资料，然后一次问我一个简单问题，帮我整理成 landing-page-brief.md：网站的唯一目标、目标客户、3 个真实卖点、价格或优惠（有才写）、联络方式（WhatsApp 或表格）、常见问题、想要的风格和颜色、有哪些照片。资料不够就写「待确认」，不要编造。整理好后给我确认。
不知道怎么回答：告诉 AI「我不确定，你给我几个选项」｜卡住：完整问题交给 AI，或举手问 Adrian

Prompt 07B　制作 Landing Page
请根据 landing-page-brief.md，帮我制作一个单页 Landing Page（index.html）。结构：Header（Logo、导航、主按钮）→ Hero（一句话标题＋副标题＋主按钮）→ 3 个卖点 → 真实证明（没有就不放）→ 常见问题 → 行动呼吁 → Footer（联络、营业时间、地址）。要求：手机和电脑都好看；主按钮文字用动词；文案简短、写给顾客；只能使用真实资料，不要编造折扣、评价或库存；每张图片都要加说明文字（alt）。
图片路径／排版／AI 编促销／Form 权限 → 完整问题交给 AI；仍不行举手问 Adrian｜备用：预做模板

阶段 8 · 第三步：让 AI 帮你检查

上线前，先让 AI 当一次「挑剔的顾客」

你要做

  1. 贴上 Prompt 07C
  2. AI 用手机宽度和电脑宽度各检查一次
  3. 看它给你的 Pass／Fail 清单

  • 按钮、联络链接、表格都能用
  • 图片和文字没有错
  • 没有假资料或敏感资料
Prompt 07C　检查 Landing Page
请实际打开这个页面，分别用手机宽度和电脑宽度检查：按钮、联络链接、表格、图片、错别字，以及有没有假资料或敏感资料。给我一张 Pass／Fail 清单，只修正没通过的项目。
清单太长：先修最重要的三项｜卡住：完整问题交给 AI，或举手问 Adrian
