AI Agent 两大类别：大厂成品 vs 开源自托管框架

Model ＝ 大脑｜Agent ＝ 身体；Agent 可以更换不同的大模型当大脑

工具类别核心强项配置特点
Codex大厂闭源 Agent代码编写、电脑画面操控（Computer Use）开箱即用，底层无法修改
Claude Code大厂闭源 Agent项目重构、批量读写文件、CLI 操作仅适配 Claude 系列模型
OpenClaw自托管 Agent 框架多渠道消息接入：WhatsApp／Telegram／飞书预先手写全套 MD 档案（IDENTITY／SOUL／AGENTS／TOOLS）才可开工
Hermes Agent自托管 Agent 框架自动学习：完成任务后自动生成 Skill 沉淀经验自带默认人格，无需一开始撰写大量 MD 文档
大厂 Codex／Claude Code：成品，开箱即用，限制较多，绑定模型
自托管 Hermes／OpenClaw：可自由切换 DeepSeek／Claude／Gemini 等大模型

安全只讲三件事

先管钱，再锁钥匙，最后锁好电脑

💰

API 先设预算保护

绑定信用卡后先设预算、提醒和上限；确认它是提醒还是硬性上限

🔑

密码、Token 锁起来

不贴进聊天、Prompt、Telegram、WhatsApp 或 GitHub；放进 Vault／密码管理

🔒

电脑要锁屏

你不在的时候，电脑还开着；锁屏才保得住电脑里的信息。另外：强密码 + 2FA、备份

屏幕出现密码、Token、QR、顾客资料：停止操作 · 停止投影 · 不要截图
开场

怎样让 AI 登录网站，又不把密码给它？

密码由你自己在 Bash 输入，不贴进聊天

告诉它网站和账号→说「我用 Bash 给你密码」→它把 bash 命令写给你→你自己执行并输入密码
你可以这样说我现在要登录〔XXX 网站〕，它的登录账号是 ABC@hotmail.com。我要你帮我登录，我用 Bash 给你密码。你直接把那个 bash 写给我。
密码只出现在你自己的 Bash，不会贴进聊天，AI 不会把它记录起来
OTP、验证码、2FA 仍然由你本人处理；不要把密码写进 Prompt、文件或聊天
